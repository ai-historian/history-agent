Add a source directory to the active collection at runtime, then preview its first page. Use this for a source OUTSIDE the workspace's sources/ tree — every source already under sources/ is auto-discovered and is already a collection member. The result gives the `source` ref to pass to page tools (list_pages, task, show_page, show_text). source_path: path to the source directory (absolute, or relative to the workspace); must contain a png/ subdirectory.
